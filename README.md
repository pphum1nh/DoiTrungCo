# Đời Trung Cổ

Game mô phỏng cuộc đời kiểu BitLife trong thế giới Trung cổ giả tưởng: chủng tộc, gia tộc, tước vị, Học viện Tháp Bạc, hiệp sĩ, thợ săn, dị giáo, Thảm Họa và Anh Hùng trong Lời Tiên Tri.

Chơi tại: https://pphum1nh.github.io/doitrungco/

Trên iPhone: mở link bằng Safari → Chia sẻ → Thêm vào MH chính để chơi như ứng dụng. Dữ liệu được lưu trong trình duyệt.
